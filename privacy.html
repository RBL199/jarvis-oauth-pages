Integritetspolicy för Jarvis (privat)

Senast uppdaterad: 2026-10-20

Vem använder Jarvis

Jarvis är ett privat verktyg som körs lokalt på ägarens egen dator. Det används endast med ägarens egna Google- och YouTube-konton. Inga andra användare finns.

Vilka Google-data som används

Efter ägarens godkännande i Googles inloggningsflöde använder Jarvis följande behörigheter:

  • youtube.readonly: för att läsa kanalens namn och ID och grundläggande statistik, som visningar, gillamarkeringar och kommentarer på uppladdade videor.
  • youtube.upload: för att ladda upp videor som ägaren har godkänt.

Hur data lagras och delas

  • Åtkomst- och förnyelsetoken lagras krypterat lokalt på ägarens dator.
  • Kanal-ID, kanalnamn och statistik lagras lokalt i Jarvis databaser.
  • Data säljs inte och delas inte med någon. Den används inte för reklam och inte för att träna AI-modeller.

Radering och återkallning

  • När en kanal kopplas från i Jarvis återkallas behörigheten hos Google och token raderas omedelbart. Övrig lagrad API-data för kanalen raderas inom 7 dagar.
  • Åtkomsten kan också återkallas när som helst via Googles säkerhetsinställningar: https://myaccount.google.com/permissions. Lagrad API-data raderas då inom 30 dagar.

Google och YouTube

Jarvis använder YouTube API Services. Se även YouTubes användarvillkor och Googles integritetspolicy. Användningen av data som tas emot från Google API:er följer Google API Services User Data Policy, inklusive kraven på begränsad användning (Limited Use).

English summary

Jarvis is a private tool run locally by its single owner, using only the owner's own Google and YouTube accounts. It uses youtube.readonly (channel identity and basic video statistics) and youtube.upload (uploading owner-approved videos). Tokens are stored encrypted on the owner's computer, and channel data is stored locally. No data is sold, shared, used for advertising or used to train AI models. Disconnecting a channel in Jarvis revokes access and deletes its tokens immediately; other stored API data is deleted within 7 days. Access can be revoked at any time at Google security settings, after which stored API data is deleted within 30 days. See the YouTube Terms of Service and the Google Privacy Policy. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Contact: {KONTAKT_EPOST}
