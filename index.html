Jarvis (privat)

Jarvis är ett privat, lokalt körande verktyg som används av en enda person, ägaren av rblindustries.se. Det är ingen offentlig tjänst, och inga externa användare kan registrera sig.

Jarvis använder YouTube API Services för att ladda upp videor och läsa grundläggande statistik för ägarens egna YouTube-kanaler. Det sker endast efter ägarens uttryckliga godkännande.

Integritetspolicy · Användarvillkor

English: Jarvis is a private, locally run tool used by a single person, the owner of rblindustries.se. It is not a public service. It uses YouTube API Services to upload videos to, and read basic statistics for, the owner's own YouTube channels. See the Privacy Policy and Terms of Service.
