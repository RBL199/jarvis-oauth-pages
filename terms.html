Användarvillkor för Jarvis (privat)

Senast uppdaterad: 2026-10-20

Jarvis är ett privat verktyg som endast används av ägaren. Det erbjuds inte till andra och har inga betalande användare.

Jarvis använder YouTube API Services. Den som ansluter ett YouTube-konto till Jarvis godkänner YouTubes användarvillkor. Hur data hanteras beskrivs i integritetspolicyn.

English: Jarvis is a private tool used only by its owner and is not offered to anyone else. It uses YouTube API Services. By connecting a YouTube account to Jarvis you agree to the YouTube Terms of Service. See the Privacy Policy.
